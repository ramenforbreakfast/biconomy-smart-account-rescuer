Load Your Exported Wallet

First move the wallet Privy lets you export into MetaMask. We will then find the separate Biconomy account it controls.

Before you connect
  1. Open Privy Home and select the app whose funds you want to recover.
  2. Choose Export keys and note the address of the exportable wallet. This is usually the first wallet shown—not the separate smart account below it.
  3. In MetaMask, open the account selector and use Add wallet → Import an account to import that private key.
  4. Return here, connect MetaMask, and select the exact address you exported.

Keep the private key secret. Import it into MetaMask; do not send it to anyone or paste it into the hosted recovery app.
